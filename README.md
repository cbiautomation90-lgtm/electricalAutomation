# EAM Manager

Electrical & Automation Department Management System for industrial operations.

## Stack

Next.js 14, React 18, TypeScript, Tailwind CSS, Supabase PostgreSQL/Auth/Storage, deployable on Vercel.

## Development status

- Phase 1 foundation: sign-in, protected workspace, database migrations, dashboard counts, equipment register create/read/archive baseline.
- Phase 2 in progress: breakdown report intake and automatic corrective work order generation, initial workflow progression.
- Inspections, tool calibration, preventive maintenance, KPI/manual control, automation, inventory, safety, projects, and comprehensive reports are not yet implemented.

See [setup](docs/SETUP.md) and [Vercel deployment](docs/VERCEL.md). Configure environment values using `.env.example`; do not commit secrets.
